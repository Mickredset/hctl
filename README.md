# Как запустить веб-приложение:
1. Установите Flask: pip install flask
2. Создайте структуру папок и файлов, как показано выше.
3. Сохраните каждый фрагмент кода в соответствующий файл.
4. Из корневой папки проекта (project/) выполните команду: python main.py
5. Откройте браузер и перейдите по адресу: http://127.0.0.1:5000
